## 🚀 Sobre mim

Sou **Desenvolvedor Full Stack**, formado em **Análise e Desenvolvimento de Sistemas**, com experiência no desenvolvimento e manutenção de aplicações web, APIs REST e sistemas corporativos.

Atuo principalmente com **React e TypeScript** no frontend e com **Node.js, NestJS e Express** no backend. Também possuo experiência com bancos de dados relacionais, integração entre sistemas, processamento de dados e implementação de regras de negócio.

No desenvolvimento frontend, trabalho com criação de interfaces responsivas, gerenciamento de formulários, validação de dados, consumo de APIs e gerenciamento de estado e requisições assíncronas.

No backend, desenvolvo APIs REST, integrações com serviços externos, rotinas assíncronas e soluções para armazenamento e processamento de arquivos.

Também tenho experiência com **Cloudflare**, incluindo armazenamento de arquivos e imagens utilizando o **Cloudflare R2**, além de deploy e configuração de aplicações em ambientes de nuvem.

Meu principal objetivo é desenvolver soluções organizadas, escaláveis e fáceis de manter utilizando o ecossistema **Node.js e React**.

## 📂 Projeto em Destaque

### 🪲 Besouro Sistemas

Sistema de gestão empresarial desenvolvido para atender operações comerciais reais, integrando diferentes áreas do negócio em uma única plataforma.

**Tecnologias:** React, TypeScript, Node.js, Express, Prisma, PostgreSQL, Docker e Cloudflare.

#### Principais recursos

* Controle de vendas e operações de caixa
* Gestão de estoque e movimentações
* Controle financeiro
* Relatórios e indicadores
* Gerenciamento de usuários e empresas
* Arquitetura multiempresa
* Integração entre frontend, API e banco de dados
* Validação de formulários e regras de negócio
* Armazenamento de arquivos e imagens em bucket
* Deploy e manutenção em ambiente de produção
